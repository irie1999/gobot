## 1. ★ 負けた理由は1つだけ — 利小損大

| | |
|---|---|
| 平均利益 | **6,495円** |
| 平均損失 | **14,244円** |
| 平均利益 ÷ 平均損失 | **0.456** |

```
必要勝率 = 1 ÷ (1 + 0.456) = 68.7%
実測勝率 = 67.4%
差       = -1.3pt
```

**勝率は十分に高い。1.3pt 足りないだけで負けている。**
勝ち方ではなく、**負けの大きさ**が問題。

### もし平均損失を10,000円に抑えられていたら

RR = 6,495 ÷ 10,000 = 0.65 → **必要勝率 60.6%**。
実測 67.4% なので、**大きくプラスになっていた。**
