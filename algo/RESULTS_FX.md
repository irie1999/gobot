## ❌ 先回りの前倒し仮説 — 棄却

「アノマリーは消えたのではなく、発生時刻が前倒しになっている」という仮説を検証した。

**各期間で最も成績の良かった買い時刻:**

| 期間 | 最適な買い時刻 |
|---|---|
| 2012-2014 | 00:00 |
| 2015-2016 | 03:00 |
| 2017-2018 | 04:00 |
| 2019-2020 | 06:00 |
| **2021-2022** | **02:00** ← 前倒しになっていない |

**単調な前倒しは観測されなかった。最適時刻は年ごとにバラバラ。**

★ **これは重要な副産物**: **時刻の最適化には意味がない**という証拠。
ロバストなのは「**00:00〜06:00 のどこで買ってもプラス**」という事実の方。
**パラメータを詰めるほど、翌年に裏切られる。**

## ★★ ここが最も重要な発見

**「効果が消えた」のではなく、「このサンプル数では原理的に判定できない」。**

ゴトー日リターンの標準偏差は **0.4132pp**。ここから逆算すると——

| 真の効果 | n=57 での期待t値 | |
|---:|---:|---|
| +0.040pp（旧データの実測値） | **+0.73** | 有意に届かない |
| +0.060pp | +1.10 | 届かない |
| +0.080pp | +1.46 | 届かない |

> **n=57 で t=2 に届くには、効果量が +0.1095pp 必要。**
> **旧データの効果量（+0.040pp）の 2.7倍**——そんな効果は最初から存在しない。

**つまり 1.4年のデータでは、この効果は検出不可能。**
実測の +0.0802pp は旧データの2倍あり、方向も一致しているが、**それでも統計的には何も言えない。**

## ★ ここから導かれる、運用上の重い結論

**効果量 +0.040pp を t=2 で検出するには：**

```
必要な n = (2 × 0.4132 ÷ 0.040)² ≈ 427回のゴトー日
         ≈ 7年分の連続データ
```

| | |
|---|---|
| **9.3年（n=570）** | ✅ **t=+4.45 で明確に検出できた** |
| 1.4年（n=57） | ❌ 判定不能 |
| 仮に4年（n≈245）あっても | 期待t値 ≈ **+1.5**。まだ足りない |

> **この戦略の有効性は、数ヶ月〜数年のフォワードテストでは絶対に確認できない。**

これは非常に重い制約で、次を意味する。

1. **短期の成績で「効いた/効かなくなった」と判断してはいけない**
2. **判断材料は統計ではなく「メカニズムが続いているか」**——輸入企業の決済実務が変わっていないか
3. だからこそ **「なぜ動くのかを説明できるものを選ぶ」**という設計方針が、他のどの条件より重要になる

## ★★★ なぜこれが決定的か

### ① 偽陽性テストに合格した

**EURUSD と GBPUSD は「効果が出てはいけない」対照群**だった。
もしここで効果が出ていたら、原因は次のどれかだった。

- ゴトー日という**日付そのもの**に何かある（円とは無関係）

**t = −0.16 / +0.14 で完全にゼロ。**対照群が正しくゼロを示した。

### ② メカニズムと完全に一致した

**円の実需が原因なら、円絡みのペアだけに出るはず。** 予測どおりになった。
これは「なぜ動くのかを説明できる」という設計条件が、実際に機能したということ。
