# FX 自動売買アルゴリズム — エッジ調査

**対象**: FX（24時間・平日）。**目的**: 走らせておくだけで利益を生むアルゴリズム。

---

## 0. ★★★ 最初に、最も重要な発見

FXのアノマリー研究には、**戦略選びの前提を変える実証結果**があります。

> **キャリー・モメンタム・バリューの予測力はミスプライシングに由来し、
> 「論文で公表された後」に運用成績が消える。**
> **アウトオブサンプルの平均シャープレシオは +0.39 → −0.32 に低下する。**
>
> — [Are carry, momentum and value still there in currencies?](https://www.researchgate.net/publication/361534831_Are_carry_momentum_and_value_still_there_in_currencies)

さらに:

> 通貨リターンのアノマリーは、**ヘッジファンドの資金流入とともに徐々に修正されつつある。**

### これが意味すること

| | |
|---|---|
| **「有名な戦略」ほど危険** | 論文になった時点で、裁定されて消えている可能性が高い |
| **バックテストで勝てても意味がない** | 公表前のデータでは勝ち、公表後は負ける。in-sample bias の典型 |
| **狙うべきは「消えにくい構造」か「まだ裁定されていない場所」** | |

**FXは世界最大の市場で、参加者が最も洗練されています。**
「エッジを見つける」より「消えていないエッジを見分ける」方が難しい。
暗号資産より条件は厳しいと考えてください。

---

## 1. 候補の評価

### ★★ A. ゴトー日 / 仲値アノマリー（日本固有）

**仕組み**

5・10・15・20・25・30日（ゴトー日）は輸入企業の決済が集中する。
銀行は **9:55の仲値決定**までにドルを調達するため、**仲値に向けてドル高円安**になりやすい。

**評価が分かれる点 — ここが面白い**

| 出典 | 内容 |
|---|---|
| [茨城大・鈴木智也研究室（学会発表）](https://zai.diamond.jp/articles/-/319691) | **「ゴトー日の金曜日」に絞ると儲かる**。時間帯にトレードオフがあり、**3時 or 5時買いが勝率最適・低リスク**、**0時買いが高リターン・高リスク** |
| [神戸大 学位論文](https://da.lib.kobe-u.ac.jp/da/kernel/E0042579/E0042579.pdf) | ゴトー日アノマリーを利用した投資戦略と獲得利益の分析 |
| [シストレ.COM 実測](https://www.sbifxt.co.jp/beginner/step01_4_034.html)（2025/12〜2026/5） | 9:30→9:55 の USDJPY ロング、**50回中33回プラス（勝率66%）／平均 +15pips** |
| 近年の検証 | **2016〜2020年がピーク（勝率62.93% / PF 2.25）。369取引目あたりから利益生成が明確に弱まる** |

**⚠ 減衰の兆候がはっきり出ています。** 周知されて**先回り**されているためと考えられます。

**★ だからこそ面白い点**

茨城大の論文タイトルは **「ゴトウビアノマリーの周知によって発生し得るFX売買戦略」**。
つまり——

> **アノマリーが消えたのではなく、「先回り勢」によって発生時刻が前倒しになっている。**

**先回りへの先回り**（0時・3時・5時に買う）が、今なお有効な可能性がある。
これは**日本固有の需給**に由来するので、**グローバルなヘッジファンドの裁定対象になりにくい**。
FXの中では、**最も「まだ生きている」見込みがある領域**です。

---

### ★★ B. スワップポイントのサヤ取り（異業者両建て）

**暗号資産のファンディングレート・アービトラージの、FX版**です。

```
A社で買い（買いスワップ +100円）
B社で売り（売りスワップ −80円）
   ↓
価格変動は両建てで相殺。スワップ差 20円/日 だけが積み上がる
```

**利回りの試算（USDJPY 158円・1万通貨）**

| | |
|---|---|
| スワップ差 | 20円/日 → **年 7,300円** |
| 必要証拠金 | 63,200円 × 2社 = **126,400円** |
| 変動対応バッファ込みの拘束資金 | **約30万円**（片側が5円逆行しても耐えるため） |
| **実質利回り** | **年 2〜3%** |

**⚠ リスク**

- **大相場で片方の業者だけロスカット** → 両建てが崩れて一方的なポジションが残る
- **スワップポイントは業者が改定する。逆転もある**
- 両建てを推奨しない業者がある
- 資金効率が悪い（2倍の証拠金）

**評価**: **構造的なので消えにくい**が、**利回りが低い**。
暗号資産のファンディングアービトラージ（年10〜30%）とは桁が違います。
「走らせておくだけ」の要件は満たすが、リターンが小さい。

---

### ★ C. キャリートレード

- シャープレシオは、未評価リスクをリアルタイムでヘッジすると **0.71 → 1.29** に改善（[論文](https://www.academia.edu/49234536/Carry_Trade_and_Momentum_in_Currency_Markets)）
- ⚠ **通貨クラッシュは金利差に応じて国をまたいで相関する。**流動性リスクが共通要因
- ⚠ **§0 の減衰問題の直撃を受けるカテゴリ**

**評価**: 論文は豊富だが、**公表後の劣化が実証されている**。円キャリーの巻き戻しは一撃で致命傷。

---

### ★ D. 通貨モメンタム

- **市場・バリュー・サイズと比べ、モメンタムが最高のシャープレシオ**
- ⚠ **同時に最悪のクラッシュも記録している**
- ⚠ §0 の減衰問題の直撃

**評価**: C と同じ理由で見送り。

## 2. 推奨する方針

### 第一候補: A（ゴトー日の「先回りへの先回り」）

**理由**

1. **日本固有の実需**（輸入企業の決済）に由来する。グローバルな裁定資金が入りにくい
2. **メカニズムが明確**。なぜ動くのかを説明できる ← §0 の減衰問題に対する最大の防御
3. **減衰が観測されているが、その減衰自体が新しいパターンを生んでいる**（先回りの前倒し）
4. **エントリー時刻が決まっている** → 完全自動化しやすい。「走らせておくだけ」に最も近い
5. 保有時間が短い（数時間）ので、オーバーナイトリスクが小さい

**検証すべき具体的な仮説**

| # | 仮説 |
|---|---|
| 1 | ゴトー日の 0時 / 3時 / 5時 買い → 9:55 決済 は、いまも有効か |
| 2 | **「金曜のゴトー日」**に絞ると成績が上がるか（茨城大の主張） |
| 3 | 買い時刻を年ごとに最適化すると、**先回りが年々前倒しになっている**ことが観測できるか |
| 4 | 月末・期末（3月/9月）で効果が強まるか |
| 5 | 減衰は本当に起きているか。**期間を分けて測る**（〜2015 / 2016-2020 / 2021-） |

**仮説3が最重要**です。もし「有効な買い時刻が年々早まっている」ことが観測できれば、
それは**アノマリーが消えたのではなく移動している**という証拠になり、
**来年どこに移動するか**まで見通せます。

### 第二候補: B（スワップサヤ取り）

A が検証で崩れた場合。**利回りは低いが、構造的に消えにくい。**

## 3. 検証計画

| 段階 | 内容 |
|---|---|
| **① データ取得** | USDJPY の**1分足・長期**（[HistData.com](https://www.histdata.com/) が2000年以降を無料提供） |
| **② ゴトー日カレンダー生成** | 5/10/15/20/25/30日 ＋ 休日調整（前倒しルール）。**ここを間違えると全部無意味** |
| **③ 時刻グリッド探索** | 買い時刻 0:00〜9:30 を30分刻み × 決済 9:55 で総当たり |
| **④ 期間分割検証** | 〜2015 / 2016–2020 / 2021– で分けて測る。**減衰の有無を直接見る** |
| **⑤ Walk-forward** | 各年で前年までのデータから時刻を決め、翌年で検証。**これが本番** |
| **⑥ コスト込み** | スプレッド 0.2pips + スリッページを引く |
| **⑦ ペーパートレード** | 実時間で実弾なし |
| **⑧ 実弾（最小ロット）** | |

**⑤ で崩れたら捨てます。** §0 の減衰問題があるので、
**Walk-forward を通らない戦略は、バックテストでどれだけ良くても採用しません。**

---

## 4. 正直な比較：FX vs 暗号資産

| | FX | 暗号資産 |
|---|---|---|
| 稼働 | 24時間 **5日** | **24時間 365日** |
| 市場の効率性 | **世界最高**（＝エッジが残りにくい） | まだ非効率が残る |
| **公表アノマリーの減衰** | **実証されている（OOS Sharpe −0.32）** | 相対的にまだ浅い |
| 「利回りを取るだけ」の戦略 | スワップサヤ取り **年2〜3%** | ファンディングアビトラ **年10〜30%** |
| 日本固有のエッジ | **ゴトー日（あり）** | 特になし |
| 規制の確認 | 不要（国内業者で完結） | **要確認** |

**総合すると、FXの方が難しい**です。ただし、
- **規制の壁がない**
- **ゴトー日という日本固有の余地がある**

という利点があります。**ゴトー日を軸にするなら、FXを選ぶ理由は十分あります。**
